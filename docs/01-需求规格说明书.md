## 1. 需求 1（不变）：三种题型

题库题型为**单选题、多选题、判断题**；兼容写法「单选 / 多选 / 判断」。所有新增功能（范围筛选、蓝图、模拟考试）均按此三分类处理。

## 2. 需求 2（新增 FR-10）：试卷题量与占比自定义

- FR-10.1 可分别设置**每张试卷**的单选题、多选题、判断题数量（不需要的题型填 0）。
- FR-10.2 实时显示每卷合计题数与预估满分。
- FR-10.3 蓝图可持久化保存，下次打开自动带出。

例：单选 20 / 多选 10 / 判断 10 → 每卷 40 题。

## 3. 需求 3（新增 FR-11）：一轮覆盖题库全部题目

- FR-11.1 **轮长自动计算**：

  ```
  N = max over 题型 t ( ⌈该题型题库量 n_t ÷ 该题型每卷数量 k_t⌉ )
  ```

  例：题库 120 题、每卷 40 题 → 3 张为一轮，3 张出完题库每道题都出现过。
- FR-11.2 **末卷补题**：某题型题目取尽时，剩余题目全部放入，差额从**本轮已出现过的同题型题目**中随机抽取补足，保证每张卷子题量严格等于蓝图。
- FR-11.3 **题型独立成堆**：三种题型各自维护牌堆与轮次，互不挤占。
- FR-11.4 **覆盖自检**：一轮生成后校验"本轮题目并集 == 题库全部题目"，未覆盖时明确告警并列出缺题数。
- FR-11.5 轮长允许手动调大；手动调小到不足以覆盖时必须给出明确提示（覆盖不完整）。
- FR-11.6 支持多轮（第 2 轮重新洗牌），支持固定随机种子复现同一套卷子。

## 4. 需求 4（不变）：多选题「定」固定顺序

题库答案中标注 `（定）` 的多选题（例：`答案：BC（定）`），**选项顺序永不打乱**，答案保持题库原样；在练习、按题型练习、模拟考试中一律生效。

## 5. 需求 5（细化 FR-13a）：选项打乱

- FR-13a.1 **单选题、多选题分别**提供"打乱选项顺序"开关（判断题不参与打乱）。
- FR-13a.2 打乱后答案字母自动重映射，判题与评分不受影响。
- FR-13a.3 标注「（定）」的题目在任一开关下都不打乱。
- FR-13a.4 同一道题在一次练习/考试内选项顺序保持稳定（回看不跳变）。

## 6. 需求 6（新增 FR-9 / FR-12）：练习范围与模拟考试

### 6.1 练习范围（FR-9）
- FR-9.1 **整个题库练习**：整库题目参与队列。
- FR-9.2 **按题型练习**：可只练单选题、只练多选题或只练判断题。
- FR-9.3 范围与已有四种练习模式（顺序 / 随机 / 错题重练 / 只练未做）**可叠加**，例如"只练判断题 + 错题重练"。
- FR-9.4 范围与模式切换立即重建队列，不清除进度；队列为空时给出引导提示。

### 6.2 试卷真实模拟考试（FR-12）
- FR-12.1 按既定蓝图**生成一轮试卷**（含轮次覆盖与补题），可查看本轮各卷的覆盖情况。
- FR-12.2 选择其中一张卷子（A/B/C…）开始模拟考试，或"自动取下一张未考的卷子"。
- FR-12.3 **真实考试体验**：答题过程中**不给对错反馈**，可自由跳题、改答案、查看已答/未答状态。
- FR-12.4 **交卷**后一次性评分：总分、满分、正确数、错误数、未答数、正确率、各题型得分。
- FR-12.5 **逐题解析**：成绩页可逐题查看"你的作答 / 正确答案 / 解析"，并可直接跳回卷面查看原题。
- FR-12.6 考试中的作答**计入练习进度**（已练题数、正确率、错题本），与练习模式共用同一套进度。
- FR-12.7 保留**历史成绩**（时间、卷号、蓝图、得分、正确率），最近 30 次。
- FR-12.8 未答题按错误计分（真实考试口径），并在成绩页单独标注"未答"。

## 7. 需求 7（v1.2 新增 FR-13）：练习进度延续（缺陷修复）

关闭软件再打开（或重新载入同一题库）后，练习位置必须**按题目内容**回到关闭前那道题。此前只按队列序号恢复：随机练习每次重建队列都会重新洗牌（`random.Random(None)`），只练未做每次重建队列都会重新过滤，序号在新队列里指向的是另一道题。已作答记录（已练题数、正确率、错题本、历史成绩）从未丢失，本项修复的只是"停在哪一题"。

- FR-13.1 顺序 / 随机 / 错题重练 / 只练未做四种模式一致成立。
- FR-13.2 位置按**题目指纹**恢复：落盘时保存"当前位置 + 其后若干题"的**导航窗口**（4 个指纹，`pos_fps`），恢复时按窗口顺序在重建后的队列中依次匹配。
- FR-13.3 只有窗口指纹全部命中失败时才允许退化为按序号兜底，且兜底**不得**再提示"已恢复上次练习进度"，也不得静默停在非预期题目上（宁可从头开始）。
- FR-13.4 兜底序号必须夹取到合法范围（`0 ≤ pos ≤ 队列长度 − 1`）。
- FR-13.5 只有单个 `last_fp`（无 `pos_fps`）的旧进度文件仍可恢复位置，无需迁移。

## 8. 需求 8（v1.2 新增 FR-14）：题库删减

- FR-14.1 可按**题库**把不想练的题目移出练习与组卷，删减结果持久化，重开软件后仍然生效。
- FR-14.2 **绝不修改题库原文件**；删减只作用于本软件的练习、统计与组卷。
- FR-14.3 已删减的题目不出现在：练习队列、错题本、统计口径（参与练习题数与正确率分母）、模拟考试组卷。
- FR-14.4 支持恢复：单条或批量恢复，以及一键「全部恢复」。
- FR-14.5 删减集保存在该题库**已有的进度文件**里（字段 `excluded`，`schema` 由 1 升为 2）；旧进度文件没有该字段时按空集处理，直接可用。
- FR-14.6 题库文件增删题目后，删减记录按**题目指纹**自动跟随；题库中已不存在的剔除记录在载入题库时自动清理，不无限累积。
- FR-14.7 题库改名 / 挪目录触发进度继承时，在新题库中仍能命中的剔除记录一并继承；但删减集**不参与**"内容重合度 ≥ 60%"的继承判定（该判定仍只比较作答记录）。
- FR-14.8 删减或恢复后练习队列立即重建，并尽可能停留在原来那道题；**已生成的试卷作废**（旧试卷按旧题目集生成），必须按新题目集重新生成一轮。
- FR-14.9 进度文件中的 `question_total` 仍记录**全库题数**；界面按参与练习的题目集显示题数，并单独标注「已删减 M 题」。

## 9. 需求 9（v1.2 新增 FR-15）：题库选择

- FR-15.1 自动记住最近使用过的题库：路径、名称、题数、最后使用时间；最多 32 条，按最后使用倒序，同一路径只保留一条。
- FR-15.2 可在列表中一键切换题库（双击或「载入选中题库」），不必每次走文件对话框。
- FR-15.3 支持「导入题库文件…」（原有文件对话框）与「扫描文件夹…」：递归扫描目录下受支持的题库文件加入列表，最多 500 个，跳过 `~$` 开头的 Office 临时文件；扫描只加入列表，不自动载入。
- FR-15.4 支持「移除记录」（仅移除列表记录）与「移除记录并清空进度」（额外删除该题库的进度文件）；**两者都不删除磁盘上的题库文件**，且均需二次确认。
- FR-15.5 题库文件被移动 / 删除时，该条记录置灰并标注「文件已不存在」；载入前给出可读提示，并允许直接从列表移除该记录。
- FR-15.6 启动时按「命令行参数 → 上次使用题库 → 题库库中最近一条**文件仍存在**的题库」顺序选择；上次的题库已不存在时**不报错**，退回到可用题库并在状态栏给出提示。
- FR-15.7 题库库文件损坏或字段非法时整体降级为空库，不影响启动与既有功能。

## 10. 非功能需求（增补）

| 编号 | 需求 |
|---|---|
| NFR-7 | 生成一轮试卷（1000 题以内、10 张以内）耗时 < 1 秒 |
| NFR-8 | 模拟考试评分 100 题以内 < 100 ms |
| NFR-9 | 新增功能不改变 v1.0 已有行为（练习与进度保留机制保持兼容，旧进度文件可直接读取） |
| NFR-10 | 位置恢复宁可从头开始也不停在别的题上：导航窗口指纹全部命中失败时不得返回 / 提示"已恢复" |
| NFR-11 | 题库删减与恢复只改变题目集与统计分母，不改变已练题数 / 正确率 / 错题本的计算规则；题库原文件字节不变 |
| NFR-12 | 新建的题库库文件（`%APPDATA%\PaperDrill\library.json`）损坏或字段非法时整体降级为空库，软件仍可正常启动；旧进度文件（schema 1）无需迁移直接可用 |

## 11. 边界与假设（增补）

1. 模拟考试只做"生成—作答—评分"，**不导出/不打印试卷**（导出仍由组卷版 PaperForge 承担）。
2. 分值默认：单选 1 分、多选 2 分、判断 1 分，可在界面调整。
3. 多选题评分不设部分分（少选/多选/错选均不得分）。
4. 试卷内的选项是否打乱，遵循当前的单选/多选打乱开关；「定」题除外。
5. 若题库某题型数量不足蓝图要求，允许卷内重复并在生成结果中告警。
6. 题库删减只作用于本软件；被删减的题目只要仍在题库原文件中，恢复后立即可练。
7. 题库库只记录路径与展示摘要，**不复制题库内容**；题库文件被移动 / 删除后需重新导入或重新扫描定位。
8. 「移除记录并清空进度」是唯一会删除进度数据的入口（题库文件仍保留）。
9. 位置恢复的导航窗口固定为 4 道题（`store.SESSION_WINDOW`），不随题库规模变化。

## 12. 验收标准（增补）

| 编号 | 验收项 | 判定方法 |
|---|---|---|
| AC-11 | 蓝图 20/10/10 生成每卷 40 题且题型数完全匹配 | 自动化校验每张卷的题型计数 |
| AC-12 | 一轮 N 张覆盖题库全部题目 | 校验并集 == 全库（真实 52 题库用例） |
| AC-13 | 末卷补题 | 多选 32 题 / 每卷 10 题 → 第 4 张 = 2 新 + 8 补，总数 10 |
| AC-14 | 「定」题在模拟考试中不打乱 | 选项文本与题库一致、答案保持 |
| AC-15 | 单选/多选打乱分离 | 关闭单选打乱后单选题选项保持原序，多选题仍打乱 |
| AC-16 | 按题型练习 | 队列只含所选题型，数量与题库统计一致 |
| AC-17 | 模拟考试评分 | 构造已知对错分布，总分/正确率/未答数与预期一致 |
| AC-18 | 考试成绩计入进度 | 交卷后已练题数增加、错题本增加 |
| AC-19 | 真实模拟（无即时反馈） | 答题过程中界面不出现对错信息，交卷后才显示 |
| AC-20 | 历史成绩保留 | 重新打开软件后历史成绩仍可查看 |
| AC-21 | 随机练习位置延续 | 随机模式答 25 题后关闭并重开同一题库，停在关闭前那道题（按指纹比对），而非题库中的其它题 |
| AC-22 | 只练未做模式位置延续 | 关闭前 `pos=26/308`，重开后仍为同一道题（队列长度变化也不错位） |
| AC-23 | 兜底不再假成功 | 构造"队列中不存在导航窗口内任何指纹"的场景，恢复不返回成功、界面不出现"已恢复上次练习进度" |
| AC-24 | 旧进度文件兼容 | 只有 `last_fp`（无 `pos_fps`）的 schema 1 进度文件仍能恢复到同一道题 |
| AC-25 | 删减不改题库原文件 | 删减若干题后题库文件哈希不变；重启软件后这些题仍不参与练习 |
| AC-26 | 删减影响面 | 删减后练习队列、错题本、统计分母、模拟考试组卷均不含被删减题目；界面题数与「已删减 M 题」自洽 |
| AC-27 | 删减记录跟随与清理 | 从题库删除某题后重新载入，其剔除记录被自动清理；题库改名（内容重合度 ≥ 60%）后仍能命中的剔除记录被继承 |
| AC-28 | 删减后旧试卷作废 | 删减后已生成的试卷被清空、卷面提示需重新生成，重新生成的一轮不含被删减题目 |
| AC-29 | 题库选择 | 载入两个题库后列表按最后使用倒序且各一条；Ctrl+B 打开对话框，双击即切换 |
| AC-30 | 移除记录不删文件 | 执行「移除记录」与「移除记录并清空进度」后题库文件仍在磁盘上；后者只删除该题库的进度文件 |
| AC-31 | 启动降级 | 上次题库与题库库中所有记录都不存在时软件正常启动并给出状态提示，不弹错误框 |

## 附：题库导入格式（vv1.2.0 新增）

除原有 Excel（`.xlsx/.xlsm`）、文本（`.csv/.txt`）、JSON 外，新增：

| 格式 | 版式 | 要求 |
|---|---|---|
| Word `.docx` `.docm` | 表格型 | 列头同 Excel；选项可合并在一列（`A.甲 B.乙`），自动展开 |
| Word `.docx` `.docm` | 段落文本型 | 章节标题标题型（如「一、单项选择题」）；题干/选项/答案分行或同行；答案可嵌在题干括号内（`（C）`、`（  BCE ）`、`（√）`）或独立成行（`答案：C`） |
| PDF `.pdf` | 文本型 | 读取文本层；先按段落解析，失败再按多空格分列兜底；扫描件不支持 |

约束：

1. 判断题不设选项；三题型以外的主观题/案例题章节自动跳过；
2. 无法解析的行不进入题库，但必须给出「行号 + 原因 + 题干片段」；
3. 新增依赖（python-docx、pypdf）必须可随 PyInstaller 打入单文件 exe；
4. 原有 `.xlsx/.csv/.txt/.json` 行为不得回归。

详细写法与边界见 `docs/06-Word与PDF题库导入说明.md`。
