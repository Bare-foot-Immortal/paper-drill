# Word 与 PDF 题库导入说明

> 适用版本：刷题匠 PaperDrill **v1.2.0** 起 ｜ 抽题匠 PaperForge **v1.1.0** 起

## 1. 支持的格式总览

| 格式 | 后缀 | 版式 | 说明 |
|---|---|---|---|
| Excel | `.xlsx` `.xlsm` | 表格 | 推荐方式，列头可识别同义词 |
| 文本 | `.csv` `.txt` | 表格 | 制表符/逗号/竖线分隔 |
| JSON | `.json` | 表格 | 与既有格式一致 |
| **Word** | `.docx` `.docm` | **表格型 或 段落文本型** | 两种版式自动识别，取解析出题目更多的一种 |
| **PDF** | `.pdf` | 文本型（表格兜底） | 取 PDF 文本层；**扫描件（图片）不支持** |

`.doc`（Word 97-2003 旧格式）不支持，请用 Word 另存为 `.docx`。

## 2. Word 题库：两种版式

### 2.1 表格型（与 Excel 一致）

| 题型 | 题目标题 | 选项A | 选项B | 选项C | 选项D | 解析 | 答案 |
|---|---|---|---|---|---|---|---|
| 单选题 | 深基坑工程中…属于危大工程？ | 3 米 | 5 米 | 7 米 | 10 米 | 依据… | A |
| 多选题 | 下列属于危大工程的有？ | 甲 | 乙 | 丙 | 丁 |  | ABCD |
| 判断题 | 未经论证压缩工期属于重大事故隐患。 |  |  |  |  |  | 正确 |

也支持把选项写在一列里：`选项` 列内容为 `A.甲 B.乙 C.丙 D.丁`，软件会自动拆开。

### 2.2 段落文本型（自动识别）

支持以下四类真实写法，可混用：

**① 答案嵌在题干括号里（选项分行）**
```
一、单项选择题
1、深基坑工程中，开挖深度超过（A）米（含）的基坑支护工程属于危大工程？
A.3
B.5
C.7
D.10
```

**② 答案嵌在题干括号里（选项同一行）**
```
1、模板安装作业开始前，应当首先完成的工作是（B）。
A.先行安排材料进场验收    B.完成专项方案审批与安全技术交底    C.直接组织班组开始作业    D.等待建设单位口头同意
```

**③ 题干 / 选项 / 答案 各自成行**
```
第一部分 单项选择题
题干：模板安装作业开始前应当首先完成的工作是？
A.先行安排材料进场验收 B.完成专项方案审批与安全技术交底 C.直接组织班组开始作业 D.等待建设单位口头同意
答案：B
来源：《合成示例管理规定》-第一章第一条
```

**④ 判断题（符号或文字均可）**
```
三、判断题
1、未经论证的情况下压缩合同约定工期，属于重大事故隐患。（√）
2、可以在电缆沟内充装易燃易爆危险品。（×）
3、施工单位应当对危大工程进行监测和安全巡视。（正确）
```

### 2.3 题型如何判定

按以下顺序，取第一个能定的：

1. **章节标题**：`一、单项选择题`、`第二部分 多项选择题`、`三、判断题` 等
   （`主观题 / 案例分析 / 简答 / 论述 / 计算` 等章节自动跳过，不收录）
2. **答案形态**：多字母（如 `ABCD`）→ 多选；`√×对错正确错误` → 判断；单字母 → 单选
3. 单选题章节里出现多字母答案时，**容错为多选**并在日志里提示，避免丢题

### 2.4 答案的几种写法（都能识别）

| 写法 | 示例 |
|---|---|
| 题干括号内（无空格） | `（A）`、`（ABCD）` |
| 题干括号内（带空格） | `（  BCE ）` |
| 空括号 = 作答位（不是答案） | `（  ）` 需另给 `答案：X`，否则记为坏行 |
| 独立答案行 | `答案：C`、`正确答案：ABCD`、`参考答案：B` |
| 固定顺序标记 | `答案：BC（定）` → 该题选项顺序不打乱 |
| 分隔符 | `（D、B）` 等价于 `（BD）` |

### 2.5 选项写法的兼容

- 选项字母：`A.` / `A．`（全角点）/ `A、` / `A)` 均可；支持 A～H 共 8 个选项
- 一行多选项（空格、全角空格、制表符分隔）
- 每行一个选项
- **选项与下一题题干粘在同一行**（如 `…D.项目经理5.《大体积混凝土规范》…`）会自动切开
- 题干括号里的普通内容（如「开挖深度超过 3 米（含）的」）不会被误当成答案

## 3. PDF 题库

- 读取 PDF 的**文本层**，按上面的段落规则解析；若段落解析得不到题目，会再尝试「按多空格分列」的表格化解析；
- **限制**：扫描件 / 图片版 PDF 没有文本层，无法识别，会提示
  「未能从 PDF 中提取到任何文字：该文件很可能是扫描件（图片）…」；
- 加密 PDF 会提示先解除密码保护。

实测：由 Word 导出的同一份题库，PDF 与 Word 解析结果一致（样例 45 题 vs 45 题）。

## 4. 坏行报告

解析过程中无法确定的题目不会进入题库，但会在导入后列出「行号 + 原因 + 题干片段」，例如：

```
[警告] 有 2 行未能导入：
       - 第 154 行：选项少于 2 个（实际 1）  下列属于深基坑工程危大工程的有（　　）？
       - 第 155 行：缺少答案  A.开挖深度2.9米的复杂地质基坑支护工程
```

据此可以回到源文件修补，再重新导入。

## 5. 已知边界

1. 扫描件 PDF / 图片题目需要 OCR，本版不含；
2. `.doc` 旧格式需先另存为 `.docx`；
3. 段落型题库依赖「题号 + 选项字母」结构，结构差异过大的题库建议整理为表格型；
4. 判断题不设选项；多选无部分分。
