## 1. 与组卷版的关系

| | 抽题匠 PaperForge v1.0.0（保留） | 刷题匠 PaperDrill v1.1.0（本版） |
|---|---|---|
| 定位 | 随机组卷、一轮覆盖、**导出试卷文件** | 实时答题练习、按题型练习、**模拟考试**、进度保留 |
| 目录 | `PaperForge/`（未改动） | `PaperDrill/` |
| 覆盖抽题 | 有（导出版） | 有（**练习/考试版**，见 `paper.py`，不导出） |
| 导出试卷 | 有（docx/html/txt） | **无**（明确不做，交卷只出成绩与逐题解析） |

两版独立工程、独立 exe、独立配置目录，可并存。

## 5. 关键设计一：试卷蓝图与轮次覆盖（需求 2、3）

与组卷版同源算法，此处只保留"抽题"，不渲染文件：

```
N = max over 题型 t ( ⌈n_t / k_t⌉ )        n_t = 该题型题库量，k_t = 该题型每卷配额

for t in 启用题型:
    deck = shuffle(题库[t])              # 每轮洗牌一次
    for i in 0 .. N-1:
        chunk = deck[i*k : (i+1)*k]      # 顺序切块
        if len(chunk) < k:
            pool = deck[0 : i*k]         # 本轮已出现过
            chunk += sample(pool, k-len(chunk))      # 末卷补题
            while len(chunk) < k:                    # 题库总量 < 配额
                chunk += choice(deck)
```

- **覆盖性**：切块区间在 `[0,n)` 上不重叠不遗漏 ⇒ 一轮并集 == 全题库；
- **定量性**：每张卷每题型恒为 `k_t`；
- **可复现**：固定 seed 得到同一套卷；
- **题型独立**：三种题型各自成堆，互不挤占。

实测（真实 52 题库 + 20/10/10）：轮长 6，各卷补题数 `[0, 0, 0, 18, 20, 39]`，覆盖 52/52。

## 6. 关键设计二：练习范围与打乱（需求 5、6）

```python
class Scope(Enum):        # 整个题库 / 只练单选 / 只练多选 / 只练判断
    @property qtype -> QType | None

class PracticeSession:
    def __init__(..., qtype_filter: QType | None, shuffle_single: bool, shuffle_multiple: bool)
    def rebuild(mode, qtype_filter="keep")   # 范围与模式可叠加
    def shuffle_for(qtype)                   # 单选取单开关、多选取多开关、判断题恒 False
```

- 范围过滤发生在队列构建阶段，**不影响进度统计口径**（`stats()` 看全库，`scope_stats()` 看当前范围）；
- `build_item` 对「定」题一律返回 `shuffled=False`；
- 打乱后答案通过"显示位置"重映射，判题与评分不受影响；
- 兼容 v1.0 的单开关写法（`shuffle_options` 参数与旧配置字段自动迁移为双开关）。

## 7. 关键设计三：模拟考试（需求 6 后半）

```python
class ExamSession:
    items: list[PracticeItem]        # 按卷面顺序，与选项打乱结果一并固定
    answers: dict[int, set[str]]     # 题号 → 显示字母（不保存对错）
    def set_answer / toggle / clear_answer
    def submit() -> ExamResult       # 一次性评分
```

- **真实模拟**：作答期间界面不展示任何对错信息，`ExamResult` 只在 `submit()` 时产生；
- **评分口径**：单选/判断全对得分；多选集合完全相等才得分（不设部分分）；**未答按错误计分**并单独统计；
- **进度联动**：交卷时把 40 题的对错一次性写入进度（`apply_answers` 批量落盘一次），因此错题本、已练题数、正确率同步更新；
- **成绩单**：`ExamResult.to_dict()` 追加到进度文件的 `exams` 数组（保留最近 30 条），含逐题明细摘要；
- **幂等**：重复 `submit()` 直接返回首次结果，不会重复计分或重复写成绩。

## 8. 关键设计四：进度"跟随题库"（v1.0 机制，v1.1 保持）

```
进度文件 = %APPDATA%\PaperDrill\progress\<文件名>__<全库指纹摘要>.json
记录键   = sha1(题干 + 选项)[:12]（与行号、顺序无关）
```

精确命中失败时按**内容重合度 ≥ 60%** 继承旧进度并另存为新文件（旧文件保留）；
写入用"临时文件 + `os.replace`"原子替换；损坏文件以空进度启动。v1.0 的进度文件可直接被 v1.1 读取（新增 `exams` 字段缺省为空）。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 考试作答被误当练习反馈 | `ExamSession` 不暴露对错；界面自检断言"作答期文案不含对错" |
| 未答题的统计口径争议 | 按真实考试计为错误，并在成绩页单列"未答" |
| 全对型多选题无法构造错答 | 评分按集合严格相等，少选即错；自检用它构造错答样本 |
| v1.0 旧配置/进度不兼容 | 配置字段自动迁移；进度文件新增字段可选，旧文件直接可读 |
| 与组卷版功能重叠造成混淆 | 两版独立目录与名称；关于对话框明确"本版不导出试卷" |

## 附：Word / PDF 解析设计（vv1.2.0）

### 两条解析通道

```
表格型数据源 ──> rows_to_questions(rows)         # Excel/CSV/TXT/JSON/Word表格/PDF表格兜底
段落型数据源 ──> lines_to_questions(lines)       # Word段落 / PDF文本
```

`TextLine(text, is_heading, source)` 是段落通道的输入单元；docx 按段落切分并**按软换行 `\n` 再切**，
PDF 按页 `extract_text()` 分行。

### 段落解析状态机（`lines_to_questions`）

逐行判定，优先级：章节标题 → 答案行 → 解析/来源行 → 新题起始 → 选项行 → 续行。

* **章节标题**：`一、单项选择题` / `第二部分 多项选择题`；含「案例/主观/简答/论述/计算」的章节标记为 `skip`；
* **新题起始**：`^\d{1,3}[、.．)）]`（小数点后不得紧跟数字，避免 `2.9米` 误判）或 `题干：`；
* **选项行**：`_iter_option_marks()` 扫描标记位置，兼容 `A.`、`A．`、`A、`、`A)`、`A明确内容`、`C  2.5m`，
  以及紧贴中文的 `…人员B.…`；同时排除 `ABC` 等拉丁字母串；行尾若粘连下一题题号则切出并回插行流；
* **答案**：优先独立答案行（`答案：`/`正确答案：`/`参考答案：`），否则取题干括号内**形如答案**的 token
  （多字母/单字母/`√×对错正确错误`），并把该括号替换为作答空位 `（　　）`；`（含）`、`（  ）` 等不动；
* **题型**：章节优先，答案形态兜底；单选章节出现多字母答案时容错为多选并记 warning。

### Word / PDF 读取

* `_read_docx()`：读全部表格（去重合并单元格）+ 段落行，**两种通道都跑一遍取题目更多者**；
* `_read_pdf()`：pypdf 逐页取文本；加密、无文本层（扫描件）、损坏文件分别给出可读中文提示；
* `_expand_combined_options()`：把「选项挤在一列」的表格展开为 选项A…选项H；
* 失败降级：docx 两通道都为 0 题、PDF 段落解析为 0 题时抛出可读 `ValueError`，不崩溃。
