## 2. P1：导入正确性与可启动性

1. **Word/PDF 段落解析丢题**（`bank_io.py`）
   - 题号支持 `1–6` 位数字，并能区分「58.2022 版…」（题号后跟数字）与正文小数
     「1.5 米」——用「上一题号 + 1」校验；
   - 支持「24 门窗工程…」（题号后只有空格）与「第 1 题」写法；
   - 选项行尾粘连下一题时，**先切粘连题再切选项**；要求新题号等于上一题号 + 1
     （跳号时必须 tail 明显像题干），避免把「约 5、7 米」误切；
   - 真实文件 `例\质检员…docx`：**160 → 165 题**，第 7 题 D 选项不再混入第 8 题题干。
2. **≥1000 题静默丢失**：题号宽度放宽到 6 位；1002 题测试全量导入。
3. **解析行识别**：`解析/答案解析/答案要点/【解析】` 先于答案行识别；`答案：` 必须带
   冒号/空白才匹配。修复"整题被拒 / 答案被静默改写 / 单选变多选 / 解析拼进选项"。
4. **PDF 表格兜底**：正确解包 `rows_to_questions` 的 4 元组；0 题时抛带坏行原因的
   `ValueError`，不再返回 `([],[],[],{})` 垃圾结果。
5. **`settings.json` 容错**：顶层非对象（数组/字符串/数字）→ 使用默认值；字段逐项
   类型校验；`Infinity/NaN`、字符串布尔、BOM、`__class__` 等不再导致启动失败；
   蓝图/分值/轮长有上限，防止 1e9 造成卡死/OOM。

## 3. P2：数据安全、存储与 CLI

- **考试作答保护**：`start_exam`/`start_next_unused_paper`/`generate_round`/题库删减/
  关闭窗口在"有未交卷考试"时返回失败或先弹确认（Qt 与 tkinter 双界面）；
  F9 交卷仅在考试作答视图生效；关闭窗口时用非阻塞确认（offscreen 自检跳过）。
- **「移除记录并清空进度」**：当前题库改为 `reset_progress()`（内存 + 文件一起清），
  不会再被下一次作答"复活"；题库文件缺失时按 `bank_name` 兜底清理孤儿进度。
- **位置记忆**：新格式 `positions` 存在但当前（模式, 范围）无记录时**从第 1 题开始**，
  不再借用上一个队列的指纹；旧格式（无 `positions`）仍兼容。
- **新一轮未考卷**：改用"本轮已考卷号"（内存态，随轮重置），历史成绩不再误判。
- **进度存储**：继承候选按 `updated/attempts` 择优并合并改名兄弟文件；继承时裁剪
  `records`；保存前检测文件指纹并按指纹合并（多实例并发不丢作答）；`save_session`/
  `reset`/`add_exam_record` 失败语义统一，`reset` 失败回滚内存；失败清理临时文件；
  `delete_by_key` 拒绝路径穿越；BOM/UTF-16 进度文件可读，损坏文件先备份 `.bad-*`。
- **CLI**：`--practice/--plan/--exam` 统一使用扣减后的题目集（与 GUI 一致）；保存失败
  输出警告并 exit 5；`--list-progress` 损坏文件不崩；坏输入输出一行式 `[错误]` 与稳定
  退出码；`--stats-only` 落地；参数非法/互斥组合报错；空题库 exit 3；
  `--qt-selftest` 完全隔离 `library.json`（不再污染真实 `%APPDATA%`）。
- **导入健壮性**：`分类` 不再抢占 `题型` 列（降级兜底）；两行表头自动合并；`答案选项`
  按选项列处理；`A类火灾/A票由…` 不再被弱字母切坏；PDF 页眉页脚/页码剔除；UTF-16
  「Unicode 文本」TXT 可导入；空表/仅表头给出坏行原因；选项列缺字母时明确拒绝而不是
  静默错位；数字答案（`1/2/3`）按 A/B/C 解释；无表头 3 列按「题干/选项/答案」识别；
  Word 自动编号与标题样式章节生效；docx 横向合并单元格保留列位；公式答案给出可操作提示。
- **正文保真**：题干/选项/解析改用 `normalize_display`（只整理空白），不再被 NFKC
  改写（`，`/`㎡`/`①` 等保留原样）；列头/答案比对仍用 NFKC。**题目指纹仍对正文做
  NFKC 规范化，因此旧进度文件继续命中，不会因升级丢进度。**

## 4. P3：界面与细节

- 「答对自动下一题」离开练习页/打开对话框即作废；
- 「不会，看答案」清空未提交勾选（不再画红叉）；
- Enter 在焦点按钮上激活按钮（Space 行为一致）；
- 主题切换同步顶栏统计胶囊与"进度未能保存"标签；
- 一次操作只刷新一次（页面只订阅 `state_changed`；MainWindow 不再重复驱动）；
- 成绩页保留明细选中行与右侧解析；
- 一次瞬时落盘失败恢复后，状态栏"进度未能保存"自动消失；
- 历史成绩表对坏 `accuracy` 容错；
- 考试成绩单 `blueprint` 从 0 开始计数（不再默认 20/10/10 累加）；
- Qt 检测/入口：`SystemExit` 也能回退 tkinter；`--gui` 多余参数报错；题型/解析/别名
  /表头等细节修正。

## 5. 需求确认项的处理

1. **未答题计入练习"错题"**：保持现状（FR-12.8 与既有测试 `test_exam_records_progress_and_history`
   均要求"未答按错误计"），本次未改口径；如产品决定只计分不写错题本，可再单独调整。
2. **案例分析/主观题章节跳过**：保持文档约定（`docs/06`）。
3. **`.xls` / `.doc` 旧格式**：仍不支持，但错误提示改为明确指引"另存为 `.xlsx`/`.docx`"。
4. **多实例并发**：采用"保存前合并"而非单实例锁；极端同时写仍有毫秒级窗口，但常规
   两窗口交替作答不会再丢记录。
5. **大题库题号导览**：未改虚拟化（4000 题首窗约 1s，属既有性能取舍）。
