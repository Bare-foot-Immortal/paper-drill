# 启动性能优化（v1.3.3）

> 现象：双击 `PaperDrill.exe` 后约 4–6 秒才出现窗口。目标是把"窗口可交互"时间压到
> 秒级，同时不改变任何功能与使用方式。
>
> 结论：单文件版窗口就绪 **4.4–5.6 s → 1.8–2.3 s**（-60%），体积 **98.8 MB → 39.6 MB**；
> 另提供可选本地打包的文件夹版 **约 1.0–1.3 s**（-77%，仅供本地自用，不随 Release 发布）。
> 448 项测试全通过，产物无头自检 exit=0 / ok=true。

---

## 1. 基线测量

测量口径统一为"**窗口就绪**：从进程启动到出现主窗口（`MainWindowHandle != 0`）"，
20 ms 轮询、1 次预热 + 3 次正式、取中位数。

| 形态 | 体积 | 启动时解包到 `%TEMP%` | 窗口就绪（中位数） |
|---|---|---|---|
| v1.3.2 `dist\PaperDrill.exe`（onefile + `collect-all PySide6`） | 98.8 MB | 2555 文件 / 238 MB | **4.4 s**（另一次会话复测 5.6 s，随杀软/缓存波动） |

源码方式（绕过打包）同样测了一遍，用于区分"打包开销"与"应用自身开销"：

| 阶段（源码运行，含 308 题 xlsx 题库） | 耗时 |
|---|---|
| 解释器 + 导入 `paperdrill` / `bank_io` / `PySide6.QtWidgets` | ≈ 0.19 s |
| 创建 QApplication + 应用主题/图标 | ≈ 0.33 s |
| 载入题库（openpyxl 导入 + 解析 308 题 + 进度） | ≈ 0.39 s |
| 构造 MainWindow（770 个控件、三页、刷新、重复应用主题） | ≈ 0.99 s |
| `show()` + 首帧 | ≈ 0.20 s |
| **合计** | **≈ 2.1–2.7 s** |

打包形态比源码多出的约 2 秒，来自单文件 exe 的**解包**（每次启动都要把 98.8 MB 内容
写到 `%TEMP%`）与杀软对解包产物的扫描，以及从 PyInstaller 归档导入模块的额外开销。

## 2. 根因

1. **打包把整个 PySide6 塞了进去。** `build_exe.ps1` 的 `--collect-all PySide6` 会无视
   `--exclude-module`，把 qml/（1785 文件）、translations/（200 文件）、metatypes/、
   Quick/Qml/Designer DLL、`opengl32sw.dll`（20.6 MB）、`qmlls/assistant/linguist` 工具
   全部收进包。应用实际只用 `QtCore/QtGui/QtWidgets` + 平台/样式/图片插件。
2. **窗口要等一切就绪才显示。** 主窗口构造里同步解析题库（含 openpyxl 导入 ≈ 0.19 s、
   解析 ≈ 0.21 s）并刷新全部页面，`show()` 排在这些之后。
3. **主题被重复应用。** `create_application()` 已设置整窗 QSS；`MainWindow.__init__` 又调
   `apply_theme()`，对 700+ 个已存在控件重新 polish，实测 ≈ 0.19 s。
4. **题目指纹重复计算。** `Question.fingerprint` 每次访问都做 NFKC 规范化 + SHA1；
   启动刷新一次统计就调用约 4000 次（≈ 0.09 s），之后每次练习刷新也会重复。

## 3. 优化措施

### 3.1 打包裁剪（最大收益）

新增 `packaging/PaperDrill.spec`，`build_exe.ps1` 改用它：

- 去掉 `--collect-all PySide6`，让 PyInstaller 自带的 PySide6 钩子按**实际 import 到的
  Qt 模块**收集 DLL 与插件；
- Analysis 后处理剔除：`opengl32sw.dll`、`PySide6/qml/`、`translations/`、`metatypes/`、
  `typesystems/`、`include/`、`plugins/designer/`、`plugins/qmltooling/`、
  `Qt6DBus/Qt6Designer/Qt6UiTools/Qt6DesignerComponents`、`qmlls/assistant/linguist/...` 等工具；
- 保留：`Qt6Core/Qt6Gui/Qt6Widgets/Qt6Svg/Qt6Test`、`platforms/qwindows.dll`（真实窗口）、
  `platforms/qoffscreen.dll`（无头自检）、`styles/qmodernwindowsstyle.dll`、
  9 个 imageformats 插件、iconengines、应用图标、docx 模板、tkinter 回退链。

结果：单文件 98.8 MB → **39.6 MB**；启动解包 2555 文件 / 238 MB → **109 文件 / 82 MB**。

### 3.2 窗口先显示，题库随后载入

`ui.run()` 改为：构造窗口（`autoload=False`）→ `show()` → `processEvents()` 画出首帧 →
`MainWindow.begin_startup_load()` 用零延时定时器载入题库。构造期不再解析题库，
用户先看到窗口与"正在载入题库…"提示，约 0.4 s 后题目出现。

### 3.3 主题不重复应用

`theme.apply_theme()` 记录当前生效主题；主题未变时直接返回，不重设整窗 QSS。
`MainWindow.apply_theme()` 在主题未变时也不再逐页重刷（页面构造时已用同一主题）。
切换深浅主题的行为与测试保持不变。

### 3.4 题目指纹缓存

`Question.fingerprint` 改走模块级 `lru_cache(8192)`，键为原始题干 + 选项元组；
题目内容被改写时键变化，不会返回过期指纹。

## 4. 结果

| 形态 | 体积 | 解包 | 窗口就绪（中位数） | 相对同会话基线 |
|---|---|---|---|---|
| v1.3.2 单文件（基线） | 98.8 MB | 2555 文件 / 238 MB | 4.4 s（复测 5.6 s） | — |
| **v1.3.3 单文件（`dist\PaperDrill.exe`）** | **39.6 MB** | 109 文件 / 82 MB | **1.8–2.3 s** | **-60%** |
| **v1.3.3 文件夹版（`-Portable`）** | 88.3 MB（目录） | 无需解包 | **1.0–1.3 s** | **-77%** |

两轮独立测量（每轮 1 次预热 + 3 次正式）：第一轮 1.79 / 0.97 s，第二轮（产物最终构建）
2.25 / 1.32 s；同轮旧版基线分别为 4.48 / 5.61 s。绝对秒数随杀软与系统缓存波动，
相对幅度稳定在 -60% / -77%。最终 `dist` 产物在隔离 APPDATA 下复测：**单文件 1.80 s、
文件夹版 1.03 s**（3 次中位数，20 ms 轮询）。

详细原始数据见 [`_work/perf/packaging_report.md`](../_work/perf/packaging_report.md)、
[`_work/perf/final_build_report.md`](../_work/perf/final_build_report.md)。

## 5. 正确性验证

- 全量单元测试：**448 passed, 1 skipped**（`QT_QPA_PLATFORM=offscreen`）；
- 产物无头自检：`PaperDrill.exe --qt-selftest --bank fixtures\样例题库.xlsx …` →
  **exit=0，ok=true，stage=done**（52 题、组卷 2 张、覆盖率校验、考试评分、图标/版本校验）；
- 真实启动路径：打包产物 + 隔离 APPDATA（`bank_path` 指向样例题库），主窗口在 2.28 s 出现，
  随后 UIAutomation 读到「第 1 / 52 题」「共 52 题：单选 26、多选 14、判断 12…」与首题题干，
  截图（`_work/perf/tmp/launch-final-onefile.printwindow.png`）显示练习页已完全载入；
- 版本一致性：界面标题、`packaging/version_info.txt`、README、使用说明均为 **1.3.3**；
- 代码检查：`python -m ruff check src tests tools` → All checks passed。

## 6. 风险与回退

| 改动 | 风险 | 回退 |
|---|---|---|
| 删除 `opengl32sw.dll` | 仅影响软件 OpenGL；本应用是 QWidget raster 绘制，不用 QOpenGLWidget/Qt Quick | 在 spec 的 `_TRIM_BASENAMES` 去掉该项 |
| 删除 Qt 翻译 `.qm` | 应用未安装 `QTranslator`，界面文案硬编码中文 | 去掉 `translations/` 过滤 |
| 文件夹版分发 | 必须整目录复制，单独 exe 不能启动 | 默认仍产出单文件；文件夹版为可选项 |
| 窗口先显示再载入 | 窗口出现后有约 0.4 s 的"正在载入题库…" | 删除 `begin_startup_load()` 调用即可恢复旧行为 |

## 7. 复现

```powershell
# 构建（默认单文件；-Portable 额外产出文件夹版）
powershell -ExecutionPolicy Bypass -File build_exe.ps1 -SkipTests -Portable

# 基准（隔离 APPDATA，1 次预热 + 3 次正式）
powershell -ExecutionPolicy Bypass -File _work\perf\bench_startup.ps1 `
    -Exe dist\PaperDrill.exe -Fixture fixtures\样例题库.xlsx `
    -AppDataDir _work\perf\tmp\appdata -Runs 3 -Label onefile
```
