## 一、缺陷：关闭软件再打开后不能延续上次进度

### 1.1 现象

「随机练习」模式下练习到第 N 题，关闭软件再打开并载入同一题库，练习位置**跳到题库里的另一道题**，
而不是关闭前那道。已作答记录（已练题数、正确率、错题本）不丢，只是"停在哪一题"丢了。
「只练未做」模式下同样不稳定。

### 1.2 复现

对 308 题真实题库：随机练习答 25 题（关闭前 `pos=26/308`），重开后 `pos=259/308`；
只练未做模式关闭前 `pos=26/308`，重开后 `pos=1/283`。
顺序练习模式复现不出（这正是原有测试没抓到的原因）。

### 1.3 根因

`PracticeSession.save_position()` 把"停在哪一题"记为**队列序号**：

```python
self.store.save_session(self.mode.value, self.current_question(), self.cursor, ...)
# 落盘 session = {"mode": "random", "last_fp": "<指纹>", "pos": 25, ...}
```

`restore_position()` 的正确路径是**按指纹定位**：

```python
fp = str(saved.get("last_fp", ""))
if fp and self.goto_question_fp(fp):     # ← 随机模式下会失败
    return True
```

但 `goto_question_fp(fp)` 要求这道题**存在于重建后的队列**里。`rebuild()` 在随机模式下用
`self._rng.shuffle(idx)` 重新洗牌，`PracticeSession` 构造时 `seed=None` → `random.Random(None)`
每次都是新的随机流，因此重开后队列顺序与关闭前完全不同。

`last_fp` 定位失败后代码**退化为按序号恢复**：

```python
pos = int(saved.get("pos", 0) or 0)
if 0 <= pos < len(self.order):
    self.cursor = pos        # ← 序号在新队列里指向的是另一道题
    return True              # ← 还返回 True，界面提示"已恢复上次练习进度"
```

序号在新洗牌的队列里毫无意义，于是"恢复成功"却停在别的题上。
「只练未做」模式同理：作答后该题被移出队列，`rebuild()` 重建的队列与关闭时长度/顺序都不同，
序号再次错位（且若最后一题刚答对，`cursor` 会超出新队列长度）。

### 1.4 修复

**位置永远按题目内容（指纹）恢复，序号只做最后的兜底。**

1. 落盘时不再只存 1 个指纹，而是存一个**导航窗口** `pos_fps`：当前位置 + 紧跟其后的若干道题
   （取 4 道，保证"当前题已被移出队列"时还能退到下一题）。
   窗口顺序保存，因此恢复时按窗口最近优先匹配。
2. `restore_position()` 依次尝试窗口内每个指纹；全部命中失败才用 `pos` 兜底，
   并且兜底命中时**不再返回 True**（避免再次出现"提示已恢复、实际跳题"的假成功）。
3. 兜底 `pos` 会被夹取到合法范围，避免超界。

因为 `rebuild()` 只做**过滤与重排**、不改变 `Question` 对象，指纹在四种模式下都稳定，
该修复对顺序/随机/错题/未做四种模式一致成立。

## 二、功能：题库删减（FR-14）

### 2.1 需求

在「进度管理」里能够**按题库**剔除不想练的题目：

* 剔除只作用于本软件的练习/组卷，**绝不修改题库原文件**；
* 剔除结果按题库持久化，重开软件后仍然生效；
* 被剔除的题不出现在：练习队列、错题本、统计口径、模拟考试组卷；
* 支持把已剔除的题**恢复**回来，也支持一键全部恢复；
* 题库文件本身增删题目后，剔除记录按题目指纹自动跟随。

### 2.2 设计

剔除集存在该题库**已有的进度文件**里（不新增文件），字段 `excluded`：

```json
{
  "schema": 2,
  "bank_key": "（变电土建负责人）题库__38ca6f80ef",
  "question_total": 308,
  "excluded": { "<题目指纹>": { "stem": "题干前 80 字", "ts": "2026-10-12 18:00:00" } },
  "records": { ... }
}
```

* 用 `dict` 而不是 `list`：去重天然成立，且能存题干摘要供界面显示与"失效剔除"清理；
* `schema` 升到 2，读取时缺省为空 dict，**旧文件直接可用**；
* **不进内容继承**：`_find_inheritable()` 只比较 `records`，剔除集不参与继承判定；
  继承发生时（题库改名/挪目录），旧文件的剔除指纹若仍能在新题库中命中则一并迁移；
* 题库总量 `question_total` 仍记录**全库题数**，界面显示"共 N 题（已删减 M 题）"。

### 2.3 界面

`练习 → 题库删减…`（或在「进度管理」中选中**当前题库**后点「题库删减…」按钮；选中其它题库会提示先切换）：

* 一个对话框、两个页签（`参与练习` / `已删减`），每页一个题目列表；
  两个列表共用同一套筛选：题型下拉 + 题干/选项关键词搜索；
* `参与练习` 页多选后点「删减选中题目 →」；
* `已删减` 页多选后点「← 恢复选中题目」，或点「全部恢复」；
* 「查看题目内容」显示选中题目的完整题干、选项、正确答案与解析；
* 底部实时显示 `参与练习 X 题 ／ 已删减 Y 题`；任何改动立即落盘并重建练习队列。

> 口径说明：界面标题行的「共 N 题」统计的是**扣掉删减后参与练习的题数**；
> 进度文件里的 `question_total` 与「进度管理」的「总题数」列记录的才是**题库全量题数**。

## 三、功能：题库选择（FR-15）

### 3.1 需求

* 记住**最近使用过的题库**（路径、题数、最后使用时间）；
* 一键在题库之间切换，不必每次走文件对话框；
* 可以从列表里移除不再需要的记录（**不删除磁盘上的题库文件**）；
* 记录丢失、文件被移动/删除时给出明确提示并允许重新定位。

### 3.2 设计

新增**题库库**文件 `%APPDATA%\PaperDrill\library.json`（与进度文件分离，避免污染进度目录）：

```json
{
  "schema": 1,
  "banks": [
    { "path": "C:\\...\\（变电土建负责人）题库.xlsx", "name": "（变电土建负责人）题库",
      "total": 308, "last_used": "2026-10-12 18:00:00" }
  ]
}
```

* 上限 32 条，按 `last_used` 倒序；同一路径只保留一条；
* 载入题库成功后自动 `remember()`；切换时更新 `last_used`；
* 文件损坏/字段非法时**整体降级为空库**，不影响启动。

菜单「文件 → 选择题库…」提供：

* 题库库列表（双击即切换）；
* 「导入题库文件…」走原有文件对话框；
* 「从列表移除」只删记录；
* 「扫描文件夹…」递归列出该目录下所有受支持的题库文件（`.xlsx/.xlsm/.csv/.txt/.json/.docx/.docm/.pdf`），
  一次性加入列表；
* 启动时若无显式参数，先尝试 `settings.bank_path`，再尝试题库库中最近一条，
  并按"文件是否仍存在"过滤，避免启动即报错。

## 四、影响面与回归风险

| 位置 | 改动 | 风险 |
|---|---|---|
| `store.py` | 新增 `excluded` 字段与读写、`BankLibrary`、`session_window` 落盘 | 旧进度文件向后兼容（字段缺省） |
| `practice.py` | `save_position`/`restore_position` 改为窗口指纹定位 | 顺序模式行为不变（原有测试覆盖） |
| `gui.py` | 新增两个对话框；练习/组卷改用"有效题目集" | 组卷、统计、错题本统一走有效集 |
| `config.py` | 无结构变更（题库路径仍用 `bank_path`） | — |

**不做**：不修改题库原文件；不改动 PaperForge；不改变已有进度统计口径（`stats()` 仍按传入题目集计算）。
